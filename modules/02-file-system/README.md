# 📂 Linux File System

Learn how Linux organizes files and directories, manages links, and locates files using essential command-line tools.

## 📚 Chapters

1. [Linux File System Overview](01-linux-file-system-overview.md)
2. [Filesystem Hierarchy Standard (FHS)](02-filesystem-hierarchy-standard-fhs.md)
3. [Paths and Navigation](03-paths-and-navigation.md)
4. [Files and Directories](04-files-and-directories.md)
5. [Hard Links vs Symbolic Links](05-links-hard-vs-symbolic-links.md)
6. [Finding and Locating Files](06-find-and-locate-files.md)

## 🎯 Learning Goals

- Understand the Linux filesystem structure.
- Navigate directories using absolute and relative paths.
- Create, manage, and inspect files and directories.
- Understand hard links, symbolic links, and inodes.
- Search for files using `find`, `locate`, `which`, and `whereis`.

## 🛠️ Prerequisites

- Basic Linux terminal knowledge.
- Ubuntu, WSL, or another Linux environment.

## 🚀 Practice

Complete the hands-on exercises in each chapter and practise the commands in your terminal.
