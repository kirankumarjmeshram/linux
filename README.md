## 📖 About

This repository documents my complete Linux learning journey while preparing for **DevOps**, **Cloud**, **Site Reliability Engineering (SRE)**, and **Software Engineering** interviews.

Instead of being just another collection of Linux notes, this repository is designed to become a practical Linux handbook containing:

- 📚 Structured learning modules
- 💻 Bash scripting
- 🧪 Hands-on labs
- 🚀 Mini projects
- 📄 Linux interview questions
- 📝 Command cheat sheets
- 🔧 Real-world DevOps scenarios
- 🐳 Docker & Kubernetes prerequisites
- ☁️ Cloud/Linux administration concepts

The goal is to continuously improve this repository with high-quality notes, examples, and practical exercises.
